# Independent Acceptance

1. Confirm lease continuity, exact subject, orchestration baseline, and clean start.
2. Map each acceptance item to fresh evidence.
3. Run the smallest credible focused checks, then required integrated/regression checks.
4. Inspect enough committed test/source surface to confirm negative side effects are actually asserted.
5. Preserve the immutable subject and classify failures without fixing them.
6. Write explicit PASS/FAIL, exact subjects, decisive evidence, coverage limits,
   residual risk, and final worktree state through the declared output mode.
