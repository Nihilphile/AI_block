# Focused Retest

Use after a bounded remediation.

- identify the original finding and exact remediation subject;
- verify the old failure is closed, not merely bypassed;
- exercise required negative side effects and nearby regression surface;
- do not re-run unrelated module acceptance without a Task requirement;
- state whether earlier accepted evidence still applies and why;
- return finding disposition, new evidence, limitations, and PASS/FAIL.
