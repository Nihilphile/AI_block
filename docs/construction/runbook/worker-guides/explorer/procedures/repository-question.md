# Repository Question

1. Restate the exact question and target decision.
2. Search narrowly, then follow only relevant ownership and call paths.
3. Return the answer first.
4. Provide concise file/symbol/evidence references.
5. Name the relevant state owner or boundary.
6. Report uncertainty and a next question only when it blocks the decision.

Do not self-assign follow-up coding or external research.
