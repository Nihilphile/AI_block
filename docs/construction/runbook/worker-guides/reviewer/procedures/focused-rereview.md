# Focused Re-review

Use after reviewed findings have remediation evidence.

- review only the remediation comparison and directly affected accepted behavior;
- give each prior finding an explicit open/closed disposition;
- identify any concrete defect introduced by the correction;
- classify Tester limitations as defect, blocking evidence gap, or acceptable consequence;
- avoid re-reviewing unchanged accepted material;
- recommend closeout only when no actionable finding remains.
