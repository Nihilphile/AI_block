# Explorer Lease

Explorer supplies bounded local repository or runtime evidence.

- Start from one exact question and the decision it informs.
- Prefer code, tests, configuration, history, generated schemas, and reproducible local observations.
- Separate verified facts, strong inference, and unknowns.
- Read-only by default; do not implement an apparent fix.
- Do not broaden into repository tours, external research, or architecture redesign.
