# Researching Work Guide

## Use this guide when

The assignment depends on an unresolved external fact: documented tool behavior, API, version, compatibility claim, protocol, standard, or upstream implementation.

## Working method

- Anchor research to the construction decision that is blocked.
- Prefer authoritative primary sources and exact applicable versions.
- Record publication/version context where behavior can change.
- Distinguish documented guarantee, observed behavior, and inference.
- Stop when the blocking fact is closed; do not expand into a general technology survey.

## Boundaries

- Research does not authorize implementation.
- A guide or web page does not override accepted product design.
- Stateful, costly, quota-consuming, or real-service probes require Controlled Probe authorization.
- If sources conflict or cannot establish the fact, report the uncertainty instead of inventing certainty.

## Handoff

Return a concise decision brief:

- question;
- finding;
- authoritative evidence;
- applicability and version limits;
- remaining uncertainty;
- construction implication, without making the Orchestrator's product decision.
