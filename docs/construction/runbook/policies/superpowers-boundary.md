# Superpowers Orchestration Boundary

Superpowers are optional methods, not AI_block's workflow engine.

- Do not auto-chain brainstorming, planning, implementation, testing, review, Git workflow, or subagent dispatch.
- Do not create product plans, invoke Workers, schedule review, or add ceremony because a capability recommends it.
- Reading a capability never grants all actions described by it.
- Task and Orchestrator authority determine which portion, if any, is usable now.
- Coding self-verification does not replace independent testing; self-check does not replace review.
- Testing/review findings do not authorize fixes.

Load `superpowers-methods.md` only when one capability is explicitly authorized for the current dispatch.
