# Coder Implementation

Use only after explicit `IMPLEMENTATION_AUTHORIZED`.

1. Confirm the Task or inline delta, subject, lease epoch, state context, output
   mode, and worktree still match.
2. Read the declared state context against local source/test evidence before
   writing.
3. Implement the smallest coherent behavior inside exact write scope.
4. Preserve frozen decisions, public boundaries, and unrelated work.
5. Apply the loaded Project State policy. Update only authorized current
   implementation/evidence claims on the direct card; escalate an Intent,
   ownership, or cross-module mismatch.
6. Add or update focused evidence for behavioral changes; use deterministic checks for mechanical work.
7. Run focused checks before broader regression checks.
8. If another path, Contract, dependency, or external action becomes necessary, use the loaded scope-escalation procedure and stop.
9. Record only unique evidence in the declared output and do not schedule
   independent testing or review.

The Task or inline delta governs exact files, semantics, verification, output
mode, and commit instruction. This procedure supplies method only.
