# Failure Diagnosis

1. Restate observed and expected behavior.
2. Establish a reliable reproduction or explain why none is available.
3. Use local evidence to eliminate hypotheses.
4. Identify root cause, affected owner/boundary, and smallest credible repair surface.
5. Report decisive evidence, uncertainty, and whether repair requires a new Task or authorization.

Do not modify product files under diagnosis-only authority.
