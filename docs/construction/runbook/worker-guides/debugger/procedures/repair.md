# Authorized Failure Repair

Use only when the Task explicitly grants diagnosis-and-repair authority.

- preserve the established reproduction as focused evidence;
- repair the smallest root-cause surface;
- do not absorb adjacent findings;
- verify the reproduction fails before and passes after when deterministic;
- use scope escalation for any new owner, path, Contract, or external action;
- report root cause, correction, regression evidence, and residual uncertainty.
