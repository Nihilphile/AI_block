# Coder Implementation

Use only after explicit `IMPLEMENTATION_AUTHORIZED`.

1. Confirm the Task, authorization delta, subject, lease epoch, and worktree still match.
2. Read the loaded root state README and target card against the local source/test roots before writing.
3. Implement the smallest coherent behavior inside exact write scope.
4. Preserve frozen decisions, public boundaries, and unrelated work.
5. If the authorized change alters the target card's statements, update only that card; a stale or cross-module mismatch is reported for Orchestrator direction.
6. Add or update focused evidence for behavioral changes; use deterministic checks for mechanical work.
7. Run focused checks before broader regression checks.
8. If another path, Contract, dependency, or external action becomes necessary, use the loaded scope-escalation procedure and stop.
9. Do not schedule independent testing or review.

The Task and authorization delta govern exact files, semantics, verification, Report path, and commit message. This procedure supplies method only.
